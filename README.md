# CollegeFinder

A modern, fast, and fully responsive College Discovery platform built with Next.js 14, Tailwind CSS, and Context API.

## Features Built
- **Listing & Filtering**: Client-side filtering by stream, fees, rating, and location with infinite scrolling.
- **Detail Pages**: Sticky navigation, overview stats, courses, placements, and reviews.
- **Compare**: Dedicated compare page handling up to 4 colleges. Includes a global floating compare bar.
- **Careers & Courses**: Browse career paths and explore 40+ courses.
- **Global Context**: Saved Colleges and Compare state managed efficiently via React Context & Local Storage.

## Tech Stack
- Framework: Next.js 14 (App Router)
- Styling: Tailwind CSS
- State: React Context + Hooks
- Icons: Heroicons / SVG

## Running the app
```bash
npm install
npm run dev
```
